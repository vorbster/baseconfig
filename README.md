Playbook to configure my Mac and Linux workstations after OS reinstall

Roles: 

- alacritty: Configured alacritty terminal on MacOS
- dotfiles: Clones my dotfiles from git
- homebrew: Installs HomeBrew and some packages
- linux: Configures Linux OS stuff
- macos: Configures MacOS stuff
- macports: Installs Macports and some packages
- mc: Pulls my mc settings
- neovim: Installs neovim and configs
- tmux: Installs and configures tmux
- zsh: Configures zsh
